## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/rajatdagar2005/new_portfolio.git
```

### Navigate to Project Directory

```bash
cd new_portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
